# Triggers — совместимая версия для Hikka

Автор оригинального модуля: **[@sqlmerr_m](https://t.me/sqlmerr_m)** / [sqlmerr](https://github.com/sqlmerr).

Исходный код: [sqlmerr/hikka_mods — triggers.py](https://github.com/sqlmerr/hikka_mods/blob/main/triggers.py). Лицензия оригинала: [GNU GPLv3](https://www.gnu.org/licenses/gpl-3.0.html). Авторство и лицензионное уведомление сохранены в файле.

Исправления совместимости: [troy9221/hikka_modules](https://github.com/troy9221/hikka_modules).

## Что исправлено

- Убрана внешняя зависимость `cachetools`, из-за отсутствия которой модуль не загружался. Пауза между срабатываниями реализована встроенным ограниченным кешем с монотонным временем.
- Настройка `throttle_time` применяется при загрузке модуля после чтения сохранённой конфигурации.
- Поиск без учёта регистра не изменяет исходное сообщение или сохранённый текст триггера.
- Фильтр `from_users` сравнивается с числовым `sender_id`.

Имя класса и пространство настроек `Triggers` сохранены: существующие триггеры, чаты и callback-настройки продолжают использоваться.

## Меню в Telegram

Откройте `.tmenu` — появится сообщение с нативными inline-кнопками Telegram. `.tconfig` также открывает это меню; `.tconfig ID` открывает карточку выбранного правила.

- В списке видны ID, состояние, текст триггера и действие. Большие списки разбиты на страницы по 8 правил.
- Карточка показывает текст, ответ или команду, фильтры и задержку. В ней доступны редактирование, включение/выключение и удаление.
- Кнопка «Удалить» сначала показывает карточку выбранного правила и просит подтвердить удаление. «Отмена» возвращает в карточку.
- Если правило изменилось после открытия подтверждения, меню покажет обновлённые данные и запросит подтверждение заново. Устаревшие кнопки не восстанавливают удалённые правила.
- «Создать триггер» запрашивает текст и создаёт отключённое правило. Задайте текст ответа или другое действие в карточке, затем включите правило.
- В основном меню можно включить/выключить весь модуль и добавить/убрать текущий чат.
- Управление кнопками доступно только владельцу Hikka. Для меню требуется работающий inline-бот Hikka.

ID новых правил не повторяются после удаления. Старые команды остаются доступными.

## Улучшения правил

- Проверяются тип действия, данные ответа/команды/callback, фильтры и задержка. Пустой объект `filters` допустим. Некорректное редактирование не записывается в базу.
- Исправлено обновление вложенных значений через `.tupd`, включая дробную задержку и новые необязательные фильтры.
- `.ton ID` / `.triggeron ID` включает правило; `.toff ID` / `.triggeroff ID` отключает его без удаления. Правила без поля `enabled` считаются включёнными.
- `filters.is_admin = true` разрешает срабатывание только для администратора или владельца группы. `false` не ограничивает авторов по правам.
- Ошибка одного правила не останавливает обработку остальных. Причина записывается в журнал без текста сообщения или callback-кода.
- Изменение `throttle_time` применяется сразу. При смене паузы текущий кеш ожидания сбрасывается.
- ID нового правила выбирается после максимального существующего ID, независимо от порядка списка.
- В текстовом ответе заменяется только `{text}`. Остальные фигурные скобки остаются буквальными; подставляемый текст сообщения экранируется для HTML.
- `.tget ID` возвращает корректный JSON; `.triggers` показывает состояние `enabled`.

Примеры:

```text
.toff 3
.ton 3
.tupd 3 delay 0.5
.tupd 3 filters.ignorecase true
.tupd 3 filters.is_admin true
```

## Команды

- `.triggers` — список сохранённых триггеров.
- `.triggeraddbase <текст>` / `.taddbase <текст>` ответом на сообщение — создать триггер с текстовым ответом.
- `.triggerchat` / `.tchat` — включить или выключить триггеры в текущем чате.
- `.tmenu` — открыть меню с карточками правил и удалением через подтверждение.
- `.tconfig [ID]` — открыть меню или карточку выбранного правила.
- `.triggeradd <JSON>` / `.tadd <JSON>` — добавить триггер из данных.
- `.triggerget <ID>` / `.tget <ID>` — получить данные триггера.
- `.triggerdel <ID>` / `.tdel <ID>` — удалить триггер.
- `.triggerset <ID> <JSON>` / `.tset <ID> <JSON>` — заменить данные триггера.
- `.triggerupdate <ID> <путь> <значение>` / `.tupd <ID> <путь> <значение>` — изменить значение.
- `.tcallback <ID>` ответом на Python-код — сохранить callback.

Глобальное включение задаётся настройкой `status`. Пауза между срабатываниями — `throttle_time`; изменение применяется сразу. Настройки `allow_invoke` и `allow_callback` управляют выполнением команд и сохранённого callback-кода.

## Проверка

Проверены импорт и создание конфигурации на рабочей ВМ с Hikka/Python 3.12 без `cachetools`, истечение и ограничение кеша, нулевая пауза, фильтр автора, поиск без учёта регистра и по части текста, подавление повторного срабатывания. Существующее пространство настроек сохранено. Дополнительно проверены добавление/замена/редактирование правил, отказ от записи некорректных изменений, переключение отдельных правил, фильтр администратора, изоляция ошибок и шаблоны ответа.
