# YG Quotes

Hikka-модуль для создания красивых цитат из сообщений — как настоящих, так и фейковых.

Основан на модуле «SQuotes» и API [LyoSU/quote-api](https://github.com/LyoSU/quote-api).

## Возможности

- Генерация цитат из реальных сообщений по реплаю
- Создание фейковых цитат от имени любого пользователя
- Поддержка нескольких сообщений в одной цитате
- Группировка подряд идущих сообщений от одного отправителя (скрытие аватара/имени)
- Обработка медиа: фото, стикеры, видео, видеосообщения, GIF, голосовые (с waveform)
- Отображение реплаев внутри цитаты
- Настраиваемый фон, размер, масштаб и стиль эмодзи
- Поддержка прокси для обхода блокировок

## Установка

Отправьте боту Hikka команду:

```
.dlmod https://raw.githubusercontent.com/troy9221/hikka_modules/main/fq.py
```

## Команды

### `.q` — обычные цитаты

| Пример | Описание |
|--------|----------|
| `.q` | Процитировать одно сообщение из реплая |
| `.q 2` | Процитировать 2 сообщения подряд |
| `.q 3 #2d2d2d` | 3 сообщения на тёмном фоне |
| `.q pink` | Фон по имени цвета |

### `.fq` — фейковые цитаты

| Пример | Описание |
|--------|----------|
| `.fq <@/ID> <текст>` | Цитата от указанного пользователя |
| `.fq <reply> <текст>` | Цитата от автора реплая |
| `.fq <@/ID> <текст> -r <@/ID> <текст>` | Цитата с ответом на другое сообщение |
| `.fq user1 текст; user2 текст` | Несколько сообщений в одной цитате |

## Конфигурация

| Параметр | По умолчанию | Описание |
|----------|--------------|----------|
| `type` | `quote` | Тип цитаты (`quote` или `stories`) |
| `bg_color` | `#162330` | Цвет фона цитаты (hex или имя цвета) |
| `width` | `512` | Ширина цитаты в px (200–2000) |
| `height` | `768` | Высота цитаты в px (200–2000) |
| `scale` | `2` | Масштаб рендера (1, 2 или 3) |
| `emoji_brand` | `apple` | Стиль эмодзи (apple, google, twitter и т.д.) |
| `max_messages` | `15` | Максимальное число сообщений в цитате (1–50) |
| `endpoint` | `https://kok.gay/gayotes/generate` | URL API-эндпоинта |
| `proxy` | `""` | Прокси для обхода блокировок (`http://user:pass@ip:port`) |
