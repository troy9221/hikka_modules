# LebedKA-PMLog

Hikka-модуль для логирования личных сообщений (PM) и выбранных групп в отдельные форум-чаты.

Самодостаточный модуль — не требует внешних библиотек или контроллеров. Все зависимости встроены.

## Возможности

- Логирование входящих/исходящих PM в отдельный форум-чат с топиками по каждому пользователю
- Логирование выбранных групп/супергрупп в `[LebedKA] PMLogGroups`, с отдельной темой для каждой группы
- Настраиваемые белый/чёрный списки личных чатов
- Диагностика фильтров и защита от логирования собственных чатов лога
- Обработка самоуничтожающихся (TTL) медиа — скачивание и пересылка как обычного файла
- Автоматическое обновление названий топиков при смене имени пользователя
- Пометка логов как прочитанных

## Установка

Отправьте боту Hikka команду:

```
.dlmod https://raw.githubusercontent.com/troy9221/hikka_modules/main/lebedka_pmlog.py
```

## Конфигурация

| Параметр | По умолчанию | Описание |
|----------|--------------|----------|
| `log_bots` | `False` | Логировать ли ботов |
| `log_list` | `[777000]` | Список Telegram ID для логирования/исключения |
| `log_self_destr` | `True` | Логировать ли самоуничтожающиеся медиа (нарушает ToS Telegram) |
| `realtime_names` | `True` | Обновлять названия топиков в реальном времени |
| `whitelist` | `True` | `True` — список `log_list` исключается, `False` — только чаты из списка логируются |
| `mark_read` | `True` | Помечать сообщения в логе как прочитанные |
| `log_groups` | `False` | Логировать группы/супергруппы из `log_list` в отдельный чат |

## Команды

- `.cpmlog` — показать конфигурацию текстом
- `.cpmlog <ключ> <значение>` — изменить настройку, например `.cpmlog log_groups true`
- `.pmloggroup` — добавить текущую группу в список и включить логирование групп
- `.pmlogstatus` — показать, разрешён ли текущий чат фильтром и почему сообщения могут пропускаться; фактическую доставку эта команда не проверяет
- `.pmlogadd [ID или @username]` — добавить чат/пользователя в список
- `.pmlogdel [ID или @username]` — удалить чат/пользователя из списка
- `.pmloglist` — показать список

Без аргументов `.pmlogadd` и `.pmlogdel` в группе выбирают текущую группу, даже если команда отправлена ответом на сообщение. Чтобы выбрать автора сообщения, укажите его ID явно. В личном чате ответ выбирает автора сообщения.

## Быстрая настройка групп

1. В нужной группе отправьте `.pmloggroup`.
2. Проверьте фильтр командой `.pmlogstatus`.
3. Дождитесь нового сообщения и проверьте его в **[LebedKA] PMLogGroups**.

Группы всегда логируются только из `log_list`, независимо от `whitelist`. Параметр `whitelist` задаёт режим фильтра личных чатов: `True` — исключать список, `False` — логировать только список. Каналы не логируются. История сообщений не выгружается.

Для отключения всех групп: `.cpmlog log_groups false`. Для удаления одной группы выполните в ней `.pmlogdel`.
