# Sing

«Поёт» песни текстом: правит одно сообщение — на экране одна строка, она меняется.

Работает в **Hikka** и **Lumen**. В комплекте народные куплеты и другие тексты из общественного достояния (романсы, шанти, блюз, спиричуэлс, кантри, старые хиты). Популярный рэп, рок и поп в репозиторий не входят — добавь себе через `.singadd`.

## Установка

Hikka:

```
.dlmod https://raw.githubusercontent.com/troy9221/hikka_modules/main/sing.py
```

Lumen:

```
.dlmod https://raw.githubusercontent.com/troy9221/Lumen_modules/main/sing.py
```

## Команды

| Команда | Описание |
|---------|----------|
| `.sing` | Список песен по жанрам |
| `.sing 1` | Спеть песню по номеру |
| `.sing калинка` | Спеть по названию |
| `.sing блюз` | Случайная песня жанра |
| `.sing рок` | Случайная из шанти / блюза / баллад |
| `.sing random` | Случайная из всего списка |
| `.singstop` | Остановить |
| `.singadd Название` | Своя песня: реплай на текст или .txt |
| `.singdel название` | Удалить свою песню |

Жанры для `.sing …`: `народные`, `романсы`, `шанти`, `блюз`, `спиричуэлс`, `кантри`, `хиты`, `баллады`. `.sing рэп` подскажет, как добавить свой текст.

Пауза между строками — `delay` в конфиге. Права — поле `credits` в конфиге, во время `.sing` не выводится.

## Свои песни

Чужие тексты в GitHub не кладутся. Добавляешь их только себе в базу юзербота.

1. Скопируй куплет туда, где он у тебя уже есть (файл, заметка).
2. Отправь его в Telegram: обычное сообщение или `.txt`. Каждая строка = один такт.
3. Реплай на это сообщение:

```
.singadd Группа крови
```

4. Спеть: `.sing группа крови` или номер из `.sing`.

То же одним сообщением:

```
.singadd Моя песня
Первая строка
Вторая строка
```

Права указываются в конфиге `credits` и во время песни не показываются. Свои песни не уезжают на GitHub.
