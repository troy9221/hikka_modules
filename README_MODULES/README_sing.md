# Sing

«Поёт» народные песни текстом: правит одно сообщение строка за строкой, текущая строка выделена.

Работает в **Hikka** и **Lumen**. В комплекте 10 традиционных песен (короткие куплеты). Современный поп с чужим текстом сюда не кладём.

## Установка

Hikka:

```
.dlmod https://raw.githubusercontent.com/troy9221/hikka_modules/main/sing.py
```

Lumen:

```
.dlmod https://raw.githubusercontent.com/troy9221/Lumen_modules/main/sing.py
```

## Команды

| Команда | Описание |
|---------|----------|
| `.sing` | Список песен |
| `.sing 1` | Спеть песню по номеру |
| `.sing калинка` | Спеть по названию |
| `.sing random` | Случайная |
| `.singstop` | Остановить |

Пауза между строками и сколько предыдущих строк оставлять на экране — в конфиге модуля (`delay`, `history`).
