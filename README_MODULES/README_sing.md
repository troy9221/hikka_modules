# Sing

«Поёт» песни текстом: правит одно сообщение — на экране одна строка, она меняется.

Работает в **Hikka** и **Lumen**. В комплекте 10 коротких куплетов. Чужой репертуар в репозиторий не кладётся — добавь себе через `.singadd`.

## Установка

Hikka:

```
.dlmod https://raw.githubusercontent.com/troy9221/hikka_modules/main/sing.py
```

Lumen:

```
.dlmod https://raw.githubusercontent.com/troy9221/Lumen_modules/main/sing.py
```

## Команды

| Команда | Описание |
|---------|----------|
| `.sing` | Список песен |
| `.sing 1` | Спеть песню по номеру |
| `.sing калинка` | Спеть по названию |
| `.sing random` | Случайная |
| `.singstop` | Остановить |
| `.singadd Название` | Добавить свою: реплай на текст или строки ниже названия |
| `.singdel 11` | Удалить свою песню |

Пауза между строками — `delay` в конфиге. Права на чужие тексты — только поле `credits` в конфиге, во время `.sing` не выводится.

Тексты Сектора Газа, Короля и Шута и Цоя в репозиторий не входят. Добавь их себе через `.singadd`, если есть право использовать.

## Свои песни

Реплай на куплет (каждая строка — отдельный такт) и:

```
.singadd Группа крови
```

Или сразу в одном сообщении:

```
.singadd Моя песня
Первая строка
Вторая строка
```

Свои песни живут в базе юзербота, не в GitHub.
