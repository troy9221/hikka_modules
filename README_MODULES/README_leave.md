# Just Leave

Hikka-модуль для быстрого выхода из группы или канала с прощальным сообщением.

## Возможности

- Выход из текущей группы/канала одной командой
- Прощальное сообщение с произвольным текстом
- Возможность удалить сообщение вместо отправки текста

## Установка

Отправьте боту Hikka команду:

```
.dlmod https://raw.githubusercontent.com/troy9221/hikka_modules/main/leave.py
```

## Команды

| Команда | Описание |
|---------|----------|
| `.leave` | Выйти из чата с сообщением по умолчанию («До связи.») |
| `.leave <текст>` | Выйти из чата, отправив свой текст |
| `.leave del` | Удалить своё сообщение и выйти из чата без прощания |
