# HikkaBackup: единый бэкап настроек и модулей

Обновлённый **встроенный** модуль для
[troy9221/Hikka](https://github.com/troy9221/Hikka). Он устанавливается вместе
с этой сборкой Hikka; отдельно загружать его после установки не нужно.

По существующему расписанию в ту же группу `hikka-backups` отправляется
**одно сообщение с одним ZIP-архивом**:

- `hikka-db.json` — база настроек Hikka;
- `*.py` — исходники внешних модулей текущего аккаунта, включая загруженные в память;
- `db_mods.json` — ссылки загрузчика для восстановления.

Подпись к архиву содержит команды восстановления. Ответьте на архив:

- `.restorebackup` — восстановить настройки и модули вместе;
- `.restoredb` — восстановить только настройки;
- `.restoremods` — восстановить только модули.

Частичное восстановление настроек не заменяет файлы модулей и их список загрузки.
Частичное восстановление модулей сохраняет остальные настройки. После успешного
восстановления Hikka перезапускается. Старые JSON-бэкапы настроек и ZIP-бэкапы
модулей также поддерживаются. Команды доступны только владельцу Hikka.

`.backupdb` создаёт полный архив вручную в той же группе. `.backupmods` создаёт
отдельный архив модулей. Интервал настраивается штатной `.set_backup_period`.
Файлы Telegram-сессий и посторонние файлы сервера не включаются в архив.

## Отдельный исходник

[hikka_backup.py](../hikka_backup.py) — тот же файл, что находится в
`hikka/modules/hikka_backup.py` вашей сборки.

Обновите сборку командой `.update`, либо замените встроенный файл и перезапустите
Hikka. Через `.dlmod` этот файл не устанавливается: Hikka защищает встроенные
команды от замены внешними модулями. Настройки расписания и группа сохраняются.
