# FirstContactAI

ИИ-автоответчик Hikka для новых личных чатов. Отвечает с вашего Telegram-аккаунта и в первом сообщении представляется автоответчиком. Продолжает диалог с учётом последних сообщений. При хамстве может ответить резко и использовать мат без цензуры. Точный ответ выбирает модель.

## Как получить ключ OpenAI

1. Войдите на [OpenAI Platform](https://platform.openai.com/) и откройте [API keys](https://platform.openai.com/api-keys).
2. Нажмите **Create new secret key**, выберите проект и скопируйте ключ. Полное значение показывается при создании.
3. Настройте [оплату API](https://platform.openai.com/settings/organization/billing/overview) для своей организации. Запросы оплачиваются отдельно от подписки ChatGPT. Подробности есть в [справке OpenAI](https://help.openai.com/en/articles/9039756-managing-billing-for-chatgpt-and-the-api-platform).

## Установка

Если у вас есть файл `first_contact_ai.py`, отправьте его документом в «Избранное» Telegram и ответьте на него командой `.loadmod`. Для установки из GitHub после публикации файла в `main` используйте:

```text
.dlmod https://raw.githubusercontent.com/troy9221/hikka_modules/main/first_contact_ai.py
```

В «Избранном» откройте `.config FirstContactAI`, выберите `api_key`, нажмите кнопку ввода значения и вставьте ключ в открывшееся поле. Hikka по умолчанию маскирует ключ в меню и хранит его в своей базе настроек. Держите резервные копии базы в закрытом доступе. Если поле пустое, модуль использует `OPENAI_API_KEY` из окружения процесса Hikka, если переменная задана.

После сохранения ключа выполните:

```text
.fcreply check
.fcreply on
```

`.fcreply check` выполняет один короткий тестовый запрос в OpenAI. После включения попросите человека, с которым у вас ещё нет переписки, написать вам и отправить второе сообщение после первого автоответа. Затем ответьте вручную и проверьте, что следующий входящий текст больше не вызывает автоответ.

| Команда | Действие |
|---|---|
| `.fcreply status` | Показывает состояние модуля и наличие ключа |
| `.fcreply check` | Проверяет доступ к API и модели |
| `.fcreply off` | Выключает автоответы во всех чатах |
| `.fcreply stop` | Останавливает автоответы в текущем личном чате |
| `.config FirstContactAI` | Задаёт ключ OpenAI, модель и лимит ответов |

По умолчанию используется `gpt-4.1-mini`, до 20 автоответов на чат. Если вы пишете вручную, модуль проверяет исходящие сообщения и прекращает отвечать этому собеседнику. Группы, боты и «Избранное» пропускаются. Новый чат определяется по видимой истории Telegram, поэтому удалённая история может выглядеть как новая переписка.

В OpenAI передаётся текст до 12 последних сообщений из диалога, который ведёт автоответчик. Файлы, фото и голосовые сообщения модуль не загружает. В запросах указано `store: false`. Для продолжения диалога модуль сохраняет в Hikka идентификаторы чата и сообщений, счётчик и состояние автоответчика.

## Если проверка API не проходит

| Результат | Что проверить |
|---|---|
| Ключ отсутствует | Поле `api_key` в `.config FirstContactAI` заполнено и сохранено |
| HTTP 401 | Ключ действителен и скопирован полностью |
| HTTP 403 или 404 | Проекту разрешены запросы к Responses API и доступна модель из `.config FirstContactAI` |
| HTTP 429 | Баланс, квота и лимиты запросов проекта. После ошибки модуль ждёт минуту перед новым запросом |
| Ошибка соединения | С сервера Hikka доступен `https://api.openai.com` |
