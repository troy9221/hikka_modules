# FirstContactAI

ИИ-автоответчик Hikka для новых личных чатов. Пишет короткими разговорными репликами, оформляет каждый ответ курсивом и начинает переписку без служебного приветствия. Модуль продолжает диалог с учётом последних сообщений и останавливается, когда вы отвечаете вручную. При хамстве модель может ответить резко и использовать мат без цензуры.

## Установка и обновление

В «Избранном» Telegram выполните:

```text
.dlmod https://raw.githubusercontent.com/troy9221/hikka_modules/main/first_contact_ai.py
```

Для установки из файла отправьте `first_contact_ai.py` документом в «Избранное» и ответьте на файл командой `.loadmod -fs`. Затем откройте `.config FirstContactAI` и выберите режим `backend`.

| Режим | Как подключается | Что расходует |
|---|---|---|
| `codex` | Codex CLI на сервере Hikka с входом через аккаунт ChatGPT | Лимит Codex аккаунта ChatGPT |
| `api` | Ключ OpenAI и Responses API | Баланс или API-кредиты организации |

## Режим Codex с аккаунтом ChatGPT

На сервере выполните от пользователя, под которым запущена Hikka:

```bash
npm install --global --prefix "$HOME/.local" @openai/codex &&
"$HOME/.local/bin/codex" --version
```

Включите вход по коду устройства в настройках безопасности ChatGPT. Затем выполните на сервере:

```bash
"$HOME/.local/bin/codex" login --device-auth
```

Откройте ссылку из терминала, войдите в свой аккаунт ChatGPT и подтвердите код. Проверьте вход командой `"$HOME/.local/bin/codex" login status`. Ожидаемый результат — `Logged in using ChatGPT`. [Документация Codex](https://learn.chatgpt.com/docs/auth?surface=cli)

В Telegram выберите **`.config FirstContactAI` → `backend` → `codex`**. В этом режиме модуль использует модель по умолчанию Codex CLI.

## Режим OpenAI API

1. Войдите на [OpenAI Platform](https://platform.openai.com/api-keys), нажмите **Create new secret key**, выберите проект и скопируйте ключ при создании.
2. Проверьте доступные API-кредиты или оплату в той же организации. [Настройки оплаты OpenAI API](https://platform.openai.com/settings/organization/billing/overview)
3. В Telegram выберите **`.config FirstContactAI` → `backend` → `api`**, затем сохраните ключ в поле `api_key`. Hikka маскирует его в меню и хранит в своей базе настроек. Если поле пустое, модуль читает `OPENAI_API_KEY` из окружения процесса Hikka.
4. Поле `model` задаёт модель Responses API. По умолчанию используется `gpt-4.1-mini`.

## Проверка и управление

В **`.config FirstContactAI` → `owner_gender`** выберите род для ответов от первого лица. Настройка действует в режимах `codex` и `api`.

| Значение | Форма ответа |
|---|---|
| `male` | Мужской род, например «понял» |
| `female` | Женский род, например «поняла» |
| `neutral` | Без указания рода, например «ясно». Значение по умолчанию |

Выполните `.fcreply check`. После сообщения **«Тестовый ответ получен»** выполните `.fcreply on`. Для проверки в Telegram попросите человека, с которым у вас ещё нет переписки, отправить два текстовых сообщения по очереди. После второго автоответа ответьте вручную. Следующее сообщение собеседника должно остаться без автоответа.

| Команда | Действие |
|---|---|
| `.config FirstContactAI` | Режим подключения, род ответов, ключ, модель API и лимит ответов |
| `.fcreply check` | Тестовый запрос через выбранный режим |
| `.fcreply on` | Включить автоответчик |
| `.fcreply status` | Показать состояние и способ подключения |
| `.fcreply off` | Выключить автоответы во всех чатах |
| `.fcreply stop` | Остановить автоответы в текущем личном чате |

По умолчанию лимит составляет 20 ответов на чат. Группы, боты и «Избранное» пропускаются. После полной очистки истории в вашем аккаунте Telegram первое новое входящее сообщение запускает автоответы заново. Счётчик ответов начинается с нуля, а остановка автоответов, включая команду `.fcreply stop`, снимается для новой переписки.

## Если тест не проходит

| Сообщение | Что проверить |
|---|---|
| `npm ERR! EACCES` при установке | Используйте `npm install --global --prefix "$HOME/.local" @openai/codex` |
| Codex CLI не найден | Обновите модуль до 1.2.1 или новее. Убедитесь, что `"$HOME/.local/bin/codex" --version` работает под пользователем Hikka |
| Codex просит войти через ChatGPT | Проверьте `"$HOME/.local/bin/codex" login status` под пользователем Hikka. Если задан `CODEX_HOME`, используйте тот же каталог при входе и при запуске Hikka |
| Codex сообщил о лимите | Проверьте доступный лимит Codex в настройках аккаунта ChatGPT |
| OpenAI HTTP 401 | Проверьте ключ в поле `api_key` |
| OpenAI HTTP 403 или 404 | Проверьте доступ API-проекта к Responses API и выбранной модели |
| OpenAI HTTP 429 | Проверьте баланс, квоту и лимиты API-организации. После ошибки модуль откладывает повторные запросы на минуту |

Версия 1.2.1 ищет Codex в `PATH` процесса Hikka и в `~/.local/bin` пользователя Hikka. Для установки по другому пути задайте в окружении службы `FIRSTCONTACT_CODEX_BIN` с полным путём к исполняемому файлу и перезапустите службу.

## Данные переписки

В OpenAI передаётся текст до 12 последних сообщений из диалога автоответчика. Файлы, фото и голосовые сообщения модуль не загружает. Режим `api` отправляет `store: false`. Режим `codex` запускает CLI во временной папке с `--ephemeral`, отключёнными shell, приложениями, плагинами и веб-поиском. Модуль сохраняет в Hikka идентификаторы чата и сообщений, счётчик и состояние автоответчика.
